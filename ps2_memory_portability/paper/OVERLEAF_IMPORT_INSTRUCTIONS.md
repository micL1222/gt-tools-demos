# Overleaf import

1. Upload the review-ready source ZIP as a new Overleaf project.
2. Set `main.tex` as the Main document.
3. Select pdfLaTeX.
4. Compile twice if Overleaf has not yet resolved citations and cross-references.
5. Confirm that Sections 1--5 end on page 2 and Author Notes begin on page 3.
6. Confirm the PDF title, author, course metadata, Figure 1, references, and
   Appendices A--F.
7. Replace only the verified manual-input fields listed in
   `MANUAL_INPUTS_REQUIRED.md`; do not insert invented peer or symposium data.

The ZIP deliberately excludes build products and the compiled PDF. The latter
is delivered separately in `ps2_memory_portability/submission/`.
